# 方法 路径模式 状态

    语法：/static 静态段 · /:param 参数（匹配一个非空段） · /* 通配符（匹配零或多个段）。 方法 ALL 表示与任意方法比较。下方可逐行输入真实请求样例，预演首条命中规则。

    冲突分析结果

    请求行为回归预演 （每行一条 方法 路径，按当前优先级计算首条命中规则）

    样例为真实请求：方法须为具体方法（GET/POST/…，不能是 ALL）， 路径须为具体路径（不含 :参数、* 与查询串 ?…）；空行忽略。 规则编辑、拖拽、导入或应用修复后自动重算；点击命中徽章可定位对应规则行。
